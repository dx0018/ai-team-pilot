Manual check

  1. Double-click this file. That is ?phase=write (default) and role=holder. The tab should write the IndexedDB sentinel and hold the lock.
  2. Quit the browser completely, then open this file again as index.html?phase=read in the same profile. IndexedDB should still show the sentinel, and this tab holds the lock.
  3. Leave that tab open. Open a second tab to index.html?phase=read&role=second. Web Locks passes there only when the callback receives null.
