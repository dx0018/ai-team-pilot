## Exact commands

Node.js 20 LTS or newer. Playwright 1.63.0 declares `engines.node >= 20`. The project toolchain is Node 20.

From the repo root:

```bash
npm ci
npx playwright install chrome msedge
npm run spike:t01
```

`npm ci` needs the committed `package-lock.json`. `npm install` is the fallback if the lockfile is not used.

`npx playwright install chrome msedge` is the Playwright 1.63 install for the `chrome` and `msedge` channels. On Ubuntu/Debian it installs Google Chrome Stable and Microsoft Edge Stable with the channel scripts (apt). Playwright asks for root when it is not already root. The runner then launches `channel: 'chrome'` and `channel: 'msedge'`.

The run prints one JSON line per browser (version, user agent, `isSecureContext`, the four checks, and any non-`file://` request URLs) and exits non-zero if any check fails or any request URL does not start with `file://`.

One browser at a time:

```bash
SPIKE_BROWSERS=chrome npm run spike:t01
SPIKE_BROWSERS=msedge npm run spike:t01
node tests/spike/t01.spike.js chrome
node tests/spike/t01.spike.js --browsers=msedge
```

`edge` is accepted as an alias of `msedge`.

## Manual check

1. Double-click `spikes/t01/index.html`. That is the write phase and the lock holder. The table should show the IndexedDB sentinel written, and this tab holds the lock.
2. Quit the browser completely (same profile), then open `spikes/t01/index.html?phase=read`. IndexedDB should still show the same sentinel. This tab holds the lock.
3. Leave that tab open. Open a second tab to `spikes/t01/index.html?phase=read&role=second`. Web Locks passes on that tab only when the callback receives `null`.

The page also shows the user agent and `isSecureContext`.

## Font subset

`spikes/t01/fonts/NotoSansSC-subset.woff2` is committed, with `spikes/t01/fonts/OFL.txt` (SIL OFL). Regenerating it needs fonttools (`pyftsubset`); running the spike does not. Exact command, from fonttools 4.66.1, against Noto Sans SC Regular (`NotoSansSC-Regular.otf`, notofonts/noto-cjk `Sans/SubsetOTF/SC`, version 2.004):

```bash
pyftsubset NotoSansSC-Regular.otf \
  --unicodes="U+0020-007E,U+6930,U+6D46,U+996D,U+8C22" \
  --flavor=woff2 \
  --output-file=NotoSansSC-subset.woff2 \
  --no-hinting \
  --no-layout-closure \
  --desubroutinize \
  --name-IDs='*'
```

`U+0020-007E` is Basic Latin. The four CJK code points are 椰, 浆, 饭, and 谢 (the sample `Nasi Lemak 椰浆饭 谢谢`).
